# 线上函数处置矩阵（初版）

更新：2026-09-10。范围为 CloudBase 线上 30 个函数。负责人授权的 CloudBase MCP 当前清单确认：全部为活动的代码部署事件函数；其中 25 个运行于 Node.js 18，3 个运行于 Node.js 16，2 个运行于 Node.js 12；全部未配置定时触发器，且未绑定函数层。该清单不提供安全可审计的版本/哈希、调用量或调用方。此矩阵是设计与盘点产物，不表示任何函数已迁移、下线或获准停用。

## 状态定义

- **迁移重写**：新 API 需要实现等价能力并完成合约、权限和事务测试。
- **过渡保留**：在新模块和回调桥接通过前继续运行在 CloudBase。
- **退役候选**：只在调用量、调用方、日志和负责人确认后才能停用。
- **待确认**：用途、调用者或配置尚不能证明，阻止 CloudBase 退役。

## 负责人确定的首批保留范围（2026-09-10）

负责人要求仅保留有实际应用证据的功能。以 2026-09-03 至 2026-09-10 的调用指标为准，首批新 API 迁移范围为：`address`、`admin-banner`、`admin-order`、`admin-product`、`admin-stats`、`banner`、`category`、`coupon`、`giftCard`、`login`、`order`、`product`、`scissors`、`user`，以及有独立流量的 CloudBase Run `payment-api`。

其余函数不进入第一批新 API 重写范围，调整为“观察后退役候选”。2026-08-11 至 2026-09-10 的 30 天调用指标复核显示，这 16 个函数均无调用记录。这不是下线授权：旧 CloudBase 资源仍保持不变，至少完成旧客户端覆盖核验、支付/物流回调核验和负责人最终确认后，才可停用。

## 代码来源与缺口

- 线上 30 个函数中，25 个可在 `D:\saven\cloudfunctions` 与 `E:\image\cloudfunctions` 的合并源码中找到对应目录。
- `lowcode-automation`、`lowcode-automation-preview`、`lowcode-datasource`、`lowcode-datasource-preview` 和 `wxpayFunctions` 已从线上取得受控审计副本，未执行代码。
- 本地另有 `scissorsAfterSale`，未出现在当前线上 30 函数清单；不得自动部署，应先确认其是否为本地未发布代码。
- 2026-09-10 以目录内非依赖文件的最后修改时间与线上函数修改时间作初筛：25 个有本地目录的函数中，18 个本地时间早于线上时间。这只能提示潜在版本漂移，不能作为代码不同、可停用或可发布的证据；当前 MCP 函数详情会返回源码，不能用作安全制品哈希采集。
- 同日 CloudBase 监控的最近 24 小时窗口中，30 个函数的调用与错误指标均为 0；扩展到 2026-09-03 至 2026-09-10 的 7 天窗口后，14 个函数有调用、16 个函数为零调用，错误指标仍均为 0。零调用不能证明函数或旧客户端未使用，更不能作为退役依据；但 7 天内有调用的函数应优先纳入兼容回归测试。
- 本地源码不等于当前线上制品。当前函数清单已重新采集运行时、定时触发器与层绑定；正式放行前仍需采集每个函数的版本/哈希、经隔离审查的配置名称、调用量和最近错误日志；环境变量值和任何机密不得写入该矩阵。CloudBase MCP 的函数详情会携带源码字段，不能直接用于此项采集。

## 必须先解决的安全改造

1. 所有新 API 必须使用服务端会话识别用户，禁止接受客户端传入的 OpenID、用户 ID、金额、库存结论或管理员身份。
2. `mysql-api` 不得迁移为面向客户端的通用查询 API；改为按业务资源定义的受权接口。
3. 物流和支付模块的配置迁入服务器受控机密文件或机密服务，源码和日志不得保留凭据、地址、联系电话或签名材料。
4. `sf-express` 中的运行期 DDL 必须移除，目标 schema 只由受控迁移脚本变更。

## B-01/B-02 放行缺口

本矩阵仅完成初步静态分类。2026-09-10 实时发现运行中的 CloudBase 云托管容器服务 `payment-api`，必须与云函数共同纳入处置清单。静态调用方核验已在 23 个函数上发现小程序或管理端引用；四个低代码函数、`wxpayFunctions`、`mysql-api`、`scissors-admin` 未找到直接静态引用，但均不可据此退役。详见 `docs/source-caller-evidence.md`。以下任一项未补齐，B-01/B-02 不放行：每个线上函数和云托管服务的当前配置与制品核验、调用量和调用方、负责人确认的处置状态，以及支付/物流/低代码函数的专项演练证据。
