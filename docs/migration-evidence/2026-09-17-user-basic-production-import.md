# 用户基础资料正式导入记录（2026-09-17）

## 范围

经负责人确认，本批次仅导入 `users` 的用户基础资料和服务端身份绑定。

- 允许字段：`id`、状态、OpenID/UnionID、昵称、手机号、性别、生日、职业和创建/更新时间。
- 未导入：商品、分类、轮播、地址、订单、售后、积分、优惠券、礼品卡、剪刀、媒体、支付和退款数据。
- 未切换小程序 API 流量；旧小程序仍使用 CloudBase 作为当前事实来源。

## 受控执行

1. 临时在旧 `login` 和 `user.updateInfo` 路径启用资料写入围栏，并通过无身份写入请求验证其返回维护响应。
2. 围栏生效后，以一致性只读事务生成最终用户快照；快照保存在服务器受控目录，权限为仅部署账户可读。
3. 目标库导入脚本确认目标 `users` 为空后，在单一事务内写入用户和身份绑定。
4. 导入完成后恢复旧函数原有代码和配置，并验证资料写入路径不再返回维护响应。
