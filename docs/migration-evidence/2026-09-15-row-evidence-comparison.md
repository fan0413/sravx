# 源库与目标库行证据比对工具

日期：2026-09-15  
状态：工具已完成本地验证，尚未对生产或演练数据库执行。

`server/scripts/row-baseline.mjs` 和 `row-chunks.mjs` 分别生成源库、目标库的受控元数据文件后，可使用：

```text
node server/scripts/compare-row-evidence.mjs --source <源证据文件> --target <目标证据文件>
```

工具不会连接数据库、不会读取业务行，也不会输出行内容或机密；只输出模式名称、表数量、匹配结果和差异类型。

## 校验范围

- 表是否在源库和目标库同时存在；
- 主键定义、行数、单列主键最小/最大值；
- 分块哈希证据中的列顺序、分块位置、行数和 SHA-256 摘要。

此工具只能在同一冻结窗口、同一表范围、同一分块大小生成的证据文件之间使用。任何差异都阻止数据切换，须完成记录级分析和负责人确认；全量匹配也不能替代订单、库存、积分、礼品卡和支付回调的业务对账。
