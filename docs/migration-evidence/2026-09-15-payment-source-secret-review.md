# 支付源码机密痕迹复核

日期：2026-09-15  
范围：仅限当前 Git 工作树中的支付容器源码与文档；未读取云端环境变量、支付平台配置或任何密钥值。

## 已知结论

- `cloudrun/payment-api/index.js` 和 `format-pem.js` 中命中的 PEM 文本是用于识别、规范化私钥格式的头尾标记；脱敏人工复核未发现可见的完整私钥材料被直接写入这些源文件。
- `配置指南.md` 中的 PEM 文本属于操作说明中的格式示例。
- `format-pem.js` 可将操作者提供的私钥格式化后输出到标准输出。因此它只能在受控终端使用，输出不得保存到 Git、普通文档、工单或聊天记录。

## 仍未证明的事项

本次本地源码复核不能证明或否定以下运行时事实：

- CloudBase Run、云函数、服务器或 CI 中是否仍保存有效支付私钥；
- 生产密钥是否曾在其他位置泄露；
- 支付平台证书、私钥序列号和回调配置是否与受控机密存储一致。

这些事项只能在负责人确认的受控生产核验中检查名称、版本、权限和轮换状态，不应读取或输出密钥内容。

## 后续要求

在迁移支付模块前，负责人确认后应：

1. 对支付私钥、平台证书和商户配置完成受控库存核验；
2. 如发现任何未经受控保存的有效密钥，按支付平台流程轮换，并更新所有受控部署配置；
3. 将新服务限制为从机密文件或机密服务读取密钥，应用日志、错误响应和构建产物均不得包含原文；
4. 完成验签、入站持久化、幂等重放和支付对账演练后，才能调整旧支付入口或回调路由。
