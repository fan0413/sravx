## 迁移范围

| 旧 `user` action | 新接口 | 范围 |
|---|---|---|
| `getPointsLogs` | `GET /api/v1/me/points/logs` | 仅返回当前会话用户的积分流水展示字段。 |
| `getMemberLevel` | `GET /api/v1/me/membership` | 返回由累计积分计算的会员等级、累计积分、累计消费和订单数。 |

## 隔离约束

- 用户身份只取自已验证的服务端会话，忽略请求中任何 `userId` 参数。
- 积分流水查询按 `points_logs.user_id` 过滤，限制每页最多 100 条；不返回 OpenID、手机号或头像等无关字段。
- 新接口不产生积分、调整等级、写入用户资料或修改订单。
- 小程序沿用 `authenticatedApiMigration` 开关；关闭时继续调用 CloudBase 云函数。
