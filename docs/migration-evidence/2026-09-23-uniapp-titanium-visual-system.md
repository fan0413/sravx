# 2026-09-23 UniApp 钛金属工业极简视觉更新

## 目标

在不改变页面结构、接口、数据字段、路由或交互的前提下，将 UniApp 用户端更新为黑、白与钛灰的单色视觉系统。

## 已完成

- 全局采用 SF Pro / 系统无衬线字体栈，确保微信小程序真机稳定；未引用远程 Web 字体。
- 主要操作、可点击文字、当前导航和已选状态统一使用黑色；材质、栏目眉题、说明、提示与大面积卡片使用黑色、白色和钛灰。
- 首页、选购页、购物袋、订单、用户中心及其余页面同步使用钛灰背景和中性卡片层。
- 首页系列、轮播和商品图片区，以及商品详情主图使用 `#E9EDF2 → #FFFFFF → #AEB7C3` 钛金属渐变。
- 商品详情页的型号、颜色、服务选择态与“加入购物袋”使用黑色；原有页面布局和用户流程不变。
- 商品详情页增加分层轻微上浮入场动效，依次呈现主图、标题、配置与参数区，不改变页面结构或操作路径。
- 底部 Vue 导航改为钛灰边界与蓝色当前页标识。
- 已移除用户端旧绿色 U 测试占位图引用；无商品图片时改用现有黑色 SRAVX 图案，并由钛金属渐变承托。

## 验证

- 已运行 `build:mp-weixin:target-orders-rehearsal` 并通过构建资源校验。
- 固定开发者工具入口已执行 FileUtils、文件和编译缓存重置后重新打开。
- 构建产物保持 24 个页面且 `subPackages` 为有效空数组。
