# 管理端商品全量媒体写入适配

日期：2026-09-11  
阶段：管理端迁移实现

## 本次完成

- 商品创建路径支持封面图、商品轮播图、详情图、规格图和规格卡片图。
- 每张图片均以当前管理员确认过的上传意图解析为 `catalog/products/` 下的 COS 对象键；客户端不能提交任意对象键。
- 商品参数、履约承诺、规格和全部图片字段随商品在同一 MySQL 事务中写入。
- 目标管理端创建新商品时先上传至受控草稿对象键，再执行一次创建写入；不会先创建缺图的占位商品。
- 商品编辑的目标模式仍保持关闭，待私有 COS 图片临时读取、既有图片保留语义和界面回显一起核验后再放行。

## 验证

- 目标 MySQL 已核验包含商品 JSON 图片列、参数列、剪刀卡片图、履约列，以及规格图片和卡片图列。
- API 自动测试 37 项全部通过，其中包含商品全量媒体对象必须被服务端确认的覆盖用例。
- 目标模式管理端 TypeScript 检查和生产构建通过。

## 未放行项

- 目标 COS 需配置管理端 HTTPS 域名的跨域上传规则后，浏览器端受控直传才可进行实际演练。
- 在商品创建、图片上传和前台读取演练通过前，不得切换商品管理模块或创建业务商品。
