# 管理端目标经营看板适配

日期：2026-09-11  
阶段：管理端迁移实现

## 已完成

- 目标管理模式的经营看板已改为调用目标 API。
- 当前仅统计目标库中已迁移的目录指标：商品总数、在售数、库存低于 10 的商品数和在线轮播图数。
- 用户、订单、GMV、退款、优惠券和剪刀指标在对应业务域迁移前固定为零值，并在界面明确标识为待迁移，避免混用 CloudBase 与目标库数据。

## 验证

- API 自动测试 38 项全部通过。
- 目标模式管理端生产构建通过。

## 边界

本看板不是经营数据正式切换，也不构成订单或资金数据的迁移验收。交易类统计应在订单、支付、退款和对账模块完整迁移后再接入。
