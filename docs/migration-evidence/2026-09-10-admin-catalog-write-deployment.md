# 分类与轮播图受控写入部署记录

- 时间：2026-09-10（Asia/Shanghai）

## 实现

- `POST /api/v1/admin/categories` 与 `POST /api/v1/admin/banners` 仅允许有效管理员会话中的 `catalog_editor` 角色。
- 分类可选图片、轮播图必需图片均须提供当前管理员已确认的媒体上传意图 ID。
- 服务端仅接受匹配 `catalog/categories/` 或 `catalog/banners/` 前缀的已确认对象键，不接受任意 URL、`cloud://` 标识或客户端指定的对象键。
- 输入字段有长度、布尔值、整数范围及轮播跳转类型校验；数据库写入使用绑定参数。
