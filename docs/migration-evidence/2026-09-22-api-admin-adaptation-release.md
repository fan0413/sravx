# API 与管理端适配发布记录

日期：2026-09-22。范围：目标 API 的管理端适配代码，以及管理端目标模式静态制品。

## 发布内容

- API 发布至 `/opt/sravx-api`，发布清单核验 88 个文件一致。
- 管理端发布至 `/var/www/sravx-admin`，启用目录与运营两类目标模式，并使用 `https://api.sravxpet.com` 作为目标 API 地址。
- 本轮包含商品删除的目标会话路径、退款服务端筛选与详情、用户资料只读边界，以及目录/运营角色的菜单与路由边界。
- 优惠券和礼品卡仍在目标模式隐藏；没有执行结构化 SKU 数据库迁移，也没有启用结构化结账开关。

## 发布过程与回退

- 第一次 API 原子切换后，服务尚未完成监听时即执行健康检查，脚本自动恢复旧版；管理端未在该次尝试中切换。
- 随后以最多十秒的就绪等待重试。API 健康后才切换管理端静态制品。
- 上一版 API 和管理端静态文件均保留在服务器回退目录，未删除任何旧制品。

## 同源登录修正

- 首次管理端制品将目标 API 地址编译为 `https://api.sravxpet.com`。管理端页面与 API 域名不同，浏览器因此拦截登录请求并显示网络错误。
- 已重新构建并仅替换管理端静态制品，使目标 API 地址为空值，浏览器请求改为同域 `/api/`；既有 Nginx 反向代理转发至本机 API。
- 修正后，管理端首页返回 `200`，同域管理员登录入口对无效请求返回预期的 `401`，API 服务未再次替换。

## 发布后核验

- `sravx-api` 与 `nginx` 均为 active。
- 服务器本机 `/health` 与 `/readyz` 均返回成功。
- 未携带管理员会话请求后台退款列表返回 `401`。
- `https://api.sravxpet.com/api/v1/catalog/home` 与 `https://admin.sravxpet.com/` 均返回 `200`。
- 管理端入口引用最终同源静态资源；目标认证制品不再包含跨域 API 地址。

## 未执行事项

- 未执行数据库迁移、未写入业务数据、未新增或修改商品、库存、订单、积分、优惠券、礼品卡、剪刀或售后记录。
- 未发布小程序、未修改微信平台、未发起真实支付、退款或物流操作。
- 后续需由业务负责人使用管理员账号验收目录与运营页面；该验收不应创建商品或变更订单，除非另行授权。
