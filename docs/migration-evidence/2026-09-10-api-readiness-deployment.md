# API 就绪检查部署记录

- 时间：2026-09-10（Asia/Shanghai）

## 变更

- 保留 `/health` 作为 Node 进程存活检查。
- 新增 `/readyz`：运行时执行受控的 MySQL `SELECT 1`；成功返回 200，连接不可用或未配置时返回 503，不暴露底层错误或连接信息。
- 候选 Nginx 配置改为仅把 `/readyz` 作为公共反向代理健康探针。

## 验证

- 本地：`npm test`，35/35 通过，覆盖依赖可用与不可用的就绪状态。
- 服务器：服务重启后为 active；本机 `/health` 与 `/readyz` 均返回成功。
- 未修改任何业务表、对象存储对象、Nginx 生效配置或公网路由。
