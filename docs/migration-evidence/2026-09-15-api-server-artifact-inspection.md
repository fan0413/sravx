# API 服务器制品核验（2026-09-15）

## 结论

- 目标服务器的 `sravx-api.service` 为 `active`；本机 `/health` 与 `/readyz` 均返回成功。
- 服务以非 root 的 `deploy` 用户运行，工作目录为 `/opt/sravx-api`，仅提供本机监听的隔离 API 骨架；尚未开放公网 API。
- 服务器部署目录不含 Git 元数据，不能以提交号直接验证制品来源。
- 服务器 `package-lock.json` 的 SHA-256 与本地当前版本一致；`src/server.js` 的 SHA-256 与本地当前版本不同，且服务器文件时间为 2026-09-11。
- 本地自 9 月 11 日以后新增的地址、工具档案、订单、售后、礼品卡、用户活动与手机号绑定等 API 准备工作尚未部署到服务器。

## 运行边界

服务单元读取受限环境文件中的数据库、API 与 COS 配置；本次核验未读取这些文件、未输出任何机密，也未对服务器、数据库或公网入口执行写操作。

## 后续要求

在获得生产部署授权且完成对应迁移门槛前，不将本地 2026-09-15 API 制品更新到 `/opt/sravx-api`，不重启服务，不开放反向代理或公网路由。

后续部署应采用含提交号与制品 SHA-256 的不可变发布包（或受控 Git 检出），并在部署记录中同时保留版本、哈希、测试结果和健康检查摘要。
