# API 最小审计日志与脱敏边界（2026-09-15）

本地运行时已接入结构化请求审计事件，记录字段仅为：事件类型、服务端请求标识、HTTP 方法、前三段固定路由分组、响应状态码与耗时。

日志不会记录查询参数、请求体、认证头、完整资源路径、用户资料、地址、手机号、支付材料或会话令牌。路由分组最多保留 `/api/v1/<资源>`，因此不会把序列号、订单号等路径参数写入日志。

本地测试以包含手机号查询参数、认证头和序列号路径的请求验证：审计记录中不含这些内容，且响应正常完成。该日志仅输出到运行进程的标准输出，部署后应由受限的系统日志与告警规则接收；日志留存期、访问人和告警阈值尚未确定，C-03 仍未放行。
