## 当前可用的新服务能力

- 管理员独立登录、会话撤销、`catalog_editor` 角色约束。
- 分类、普通商品、商品规格、轮播图的后台只读查询。
- 私有 COS 的受控上传意图、服务端对象核验与确认。

## 风险边界

- 不把 `admin-order`、`giftCard`、`admin-coupon`、`admin-points-product`、`sf-express` 或支付相关调用接入新服务，直到其事务、入站持久化、幂等和回归演练齐备。
- 商品写入必须传入实际履约信息；目标 `products` 和 `product_specs` 中的发货类型、时效、承诺、延迟原因与说明均为非空字段，不能以默认或猜测内容代替。
- 当前管理端构建产物仍调用 CloudBase，尚未发布到新入口；不能据此关闭原后台或 CloudBase 函数。

## 下一批实现顺序

1. 分类与轮播图的受控写入，要求关联图片先通过 COS 上传意图确认。
2. 商品表单与规格表单的字段映射、履约校验和库存审计设计。
3. 在隔离环境完成后台前端的 API 适配，再迁移交易和支付之外的模块。
