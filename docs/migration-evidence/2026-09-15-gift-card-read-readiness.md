# 礼品卡只读接口放行检查

日期：2026-09-15  
状态：工具与接口已就绪，尚未对任何生产环境启用。

## 已完成

- 新增仅本人可读的 `GET /api/v1/gift-card-redemptions`。身份只来自已签名的服务端会话；忽略任何客户端传入的用户标识。
- 返回兑换记录展示所需的标题、权益摘要、履约状态、订单关联和时间；不返回礼品卡兑换码或完整权益快照。
- 小程序仅在 `authenticatedApiMigration.enabled` 开启时调用目标接口，默认继续调用旧云函数。
- 兑换、补充地址、积分入账、优惠券发放和订单创建均不属于本次迁移范围。

## 切换前只读核验

在获得目标库只读访问授权、且已完成数据导入演练后，使用受控迁移账号运行：

```text
node server/scripts/check-gift-card-integrity.mjs --database <目标数据库名>
```

工具只输出汇总计数，不输出兑换码、用户标识或业务行。以下计数必须全部为 `0`，`readyForUserScopedReads` 才会为 `true`：

- 兑换记录没有有效 `user_id` 或关联不到用户；
- 兑换记录关联不到礼品卡；
- 已兑换礼品卡缺少兑换记录；
- 同一礼品卡对应多条兑换记录。

任一检查失败，保持小程序开关关闭，先在迁移演练中修复映射或历史例外；不得以 `_openid` 回退查询来绕过目标用户 ID 隔离。
