# 微信手机号绑定接口迁移记录

日期：2026-09-15  
状态：本地代码与回归测试完成；未部署、未启用小程序调用、未调用微信接口。

## 新接口

`POST /api/v1/me/phone`

请求仅包含微信 `getPhoneNumber` 返回的临时 `code`。服务端使用小程序受控凭据获取微信访问令牌，并调用微信手机号接口验证该凭证；验证成功后，只向当前已签名会话对应的活动用户写入手机号。

## 安全约束

- 不接受客户端提交的手机号、OpenID 或用户 ID；
- 微信访问令牌仅保留在服务端内存缓存，错误响应和日志不返回授权凭证、访问令牌或手机号；
- 上游请求固定为 HTTPS，并设置五秒超时；
- 手机号写入以 `users.id` 和活动状态为条件，不能跨用户覆盖；
- 该接口不创建订单、积分、优惠券或支付记录。

## 尚未启用的原因

小程序现有注册页仍使用 CloudBase 的 `cloudID`、加密数据和手机号 code 兼容路径。目标接口只接受当前微信推荐的临时 code，因此需要在负责人确认手机号收集说明、注册兼容方案和真机演练范围后，再接入迁移开关。

在此之前，旧登录函数保持运行，新接口不接收真实手机号数据。
