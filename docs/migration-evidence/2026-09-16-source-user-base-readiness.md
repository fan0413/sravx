# 源用户基础资料只读核验（2026-09-16）

## 访问方式

通过已绑定的 `mcp-sravx` 对当前 CloudBase 环境关联 MySQL 执行只读结构与汇总查询。实例状态为可用。查询未读取或输出用户资料、手机号、OpenID、UnionID、头像或其他业务明细。

## 核验结果

- 源 `users` 表包含本批所需的 `id`、`status`、`openid`、`_openid`、`unionid`、用户名、手机号、性别、生日、职业及审计时间字段。
- `openid` 具有唯一索引；`unionid` 具有唯一索引；`id` 为主键。
- 当前共有 52 个用户，全部具有 OpenID 与 `_openid`，二者未发现不一致；无 UnionID 值。
- 未发现重复 OpenID 或重复 `_openid`；全部账户状态为 active。
- `avatar`、积分、累计消费、订单数和会员等级字段存在，但均不在本批导出白名单内。

## 结论

源端的用户身份基础数据满足进入隔离导入预检的条件。该结论不替代目标库结构核验，也不表示已经导出或导入用户数据。

## 后续边界

MCP 的只读查询用于结构和汇总核验；不得通过 MCP 将用户行明细、连接凭据或快照内容返回到对话。原始快照仍须在受控迁移主机的私有路径生成，并按用户基础资料运行手册处理。
