## 已完成

- `admin.sravxpet.com` 的 A 记录已指向目标轻量服务器公网 IPv4。
- 已签发 `admin.sravxpet.com` 的 Let’s Encrypt 证书；证书有效期至 2026-12-10。

- 已配置基础响应安全头；生产 API 不直接对公网监听。

## 验证证据

- 权威公共 DNS 查询可返回 `admin.sravxpet.com` 的目标 IPv4。
- DNS-01 校验成功，证书主题为 `admin.sravxpet.com`。
- Nginx 配置语法检查通过，HTTPS 站点已由服务器加载；服务器访问日志记录到该站点的成功静态资源响应。

## 未放行项

从本地公网访问仍遇到腾讯备案接入拦截。该问题发生在请求到达服务器前，不能通过调整 Nginx、DNS 或证书解决。

需在腾讯云备案控制台为当前轻量服务器完成 `sravxpet.com` 的接入备案，并将该步骤的审核通过结果加入本迁移证据。接入备案通过前，不得将管理端视为已对业务人员正式可用。

## 证书维护

本证书使用 DNS-01 手动校验签发。Certbot 的定时任务会检查到期时间，但无法在没有 DNS API 凭据的情况下自动更新 TXT 校验值。应在到期前至少 30 天重新执行 DNS-01 续期，并在成功后重新加载 Nginx。

## 安全边界

- 未将任何密钥、数据库凭据、会话令牌或 ACME 校验值提交到仓库。
- 管理端的完整业务写入切换尚未完成；当前发布只完成静态承载、HTTPS 与同域 API 路由准备。
