## 已部署行为

`POST /api/v1/admin/media/upload-intents` 仅在以下条件同时满足时返回上传意图：

1. 请求携带未过期且未撤销的独立管理员会话；
2. 管理员账户仍为活动状态，并在数据库实时拥有 `catalog_editor` 角色；
3. 媒体类别、MIME 类型、文件字节数与 SHA-256 校验值通过服务端校验。

服务端生成固定业务前缀下的对象键，并将意图保存至 `media_upload_intents`。该接口目前不签发 COS 预签名地址，也不允许客户端指定任意对象键，因此尚不能上传真实文件。
