# 公网 API 候选 Nginx 配置

当前服务器配置仍对 `api.sravxpet.com` 返回 503。此目录的配置仅用于切换前审查，未写入服务器 Nginx 目录，也未执行 `nginx -s reload`。

## 候选保护

- HTTPS 仅允许 TLS 1.2/1.3；HTTP 重定向至 HTTPS。
- API 代理仅指向本机 `127.0.0.1:3000`；不会将 Node 端口直接开放到公网。
- 当前候选片段将 `/api/v1/` 请求体上限设为 16 KB；应用层 JSON 读取上限为 8 KB。媒体通过受控预签名 URL 直传，不经此 API 代理。
- 传递 Nginx 请求标识与转发协议头；API 自身会生成响应请求标识、禁止缓存并加入基础浏览器安全头。
- 当前候选片段只代理 `/health` 与 `/api/v1/`；`/readyz`、每 IP 限流、并发连接限制和 WAF 规则尚未写入候选片段，不能视为已配置。

## 仍需负责人确认的激活动作

1. 在维护窗口确认由当前 503 配置切换到候选配置。
2. 在负责人确认的候选版本中补充并复核 `http` 级限流、并发限制、`/readyz` 暴露范围和站点片段，执行 `nginx -t`。
3. 在同一窗口执行 reload，并从外部验证 HTTPS、限流、认证失败响应和回滚路径。
4. 小程序合法请求域名、DNS、证书和发布版本需按迁移放行表逐项确认；本配置不能替代这些动作。
