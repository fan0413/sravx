# 管理端目录模块试运行手册

本手册只用于分类、轮播图和普通商品目录的目标服务试运行。它不会导入历史商品、图片、用户、订单、地址、积分、优惠权益或支付数据。

## 试运行边界

- 管理端原有 CloudBase 登录和订单、退款、用户、优惠券、礼品卡、剪刀、物流页面保持原状。
- 仅分类、轮播图、普通商品及其图片上传走目标 API 和私有 COS。
- 目标数据库目录初始为空；目录内容由后台重新创建，不复用 CloudBase 的商品或媒体。
- 试运行开关由构建时环境变量 `VITE_ADMIN_CATALOG_MODE=target` 控制；未设置时维持原有 CloudBase 行为。

## 前置检查

1. 先部署与当前提交匹配的 API 制品，并确认健康检查、目录空集和未授权后台请求分别返回预期结果。
2. 目标管理员账号已存在、具有 `catalog_editor` 角色，并使用与 CloudBase 后台登录相同的账号密码。管理端登录会先建立 CloudBase 会话，再为目录模块建立独立目标 API 会话；任一失败都不得进入试运行。
3. COS 受控上传配置和目标 API 的管理员媒体接口可用。上传仅允许 JPG、PNG、WebP，并由服务端生成对象键和签名 URL。
4. 仅在受控发布目录中设置下面两个构建变量，不写入仓库、前端源码或公共文档：

```text
VITE_ADMIN_CATALOG_MODE=target
VITE_API_BASE_URL=https://api.sravxpet.com
```

## 验收顺序

1. 登录后打开分类、轮播图和商品列表，三者均应显示空状态。
2. 新建一个测试分类，上传一张测试图片后保存；编辑分类时只能保留本分类已有图片或重新上传图片。
3. 创建一个含真实履约字段的测试商品和轮播图；确认图片对象键由目标服务生成，前台读取接口只返回目标目录。
4. 在同一后台确认订单、用户、优惠券和物流页面仍从 CloudBase 读取，且没有触发目标库业务写入。
5. 删除测试目录记录或按业务决定保留；任何删除操作均由负责人执行，不作为本手册自动步骤。

## 回退

若目录 API、目标管理员会话或 COS 上传失败，恢复此前的静态后台制品并移除试运行构建变量。该回退不修改 CloudBase、订单或目标业务数据；已经由负责人创建的目标目录记录需按业务决定保留或删除。
