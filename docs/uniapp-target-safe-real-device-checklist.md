# UniApp 新 API 真机验证清单

## 使用的构建产物

导入 `E:\sravxapp\sravx\dist\build\mp-weixin`。

必须使用 `build:mp-weixin:target-safe` 构建。该构建启用新 API 的登录、资料、积分读取、地址、合作咨询和剪刀读取；订单、优惠券领取、礼品卡、剪刀写入、售后写入、真实支付和真实退款仍不切换。

## 验证步骤

1. 打开小程序并完成登录与手机号授权。
   - 预期：进入首页，不出现“未登录”；个人中心显示当前用户信息。
2. 打开“我的”。
   - 预期：积分和会员等级与当前账号一致。
3. 打开“地址管理”。
   - 预期：能读取已有地址；新增、编辑、设为默认和删除仅在人工确认后测试。
4. 打开“我的剪刀”。
   - 预期：已绑定工具可读取，保修信息与历史记录一致。
5. 打开“合作咨询”。
   - 预期：页面可正常打开；不要提交测试资料，除非业务确认允许写入。

## 记录方式

每项只记录“通过 / 不通过”、时间和匿名错误信息。不要记录手机号、地址、订单号、Token、兑换码或页面截图中的个人信息。

## 本轮禁止操作

- 不创建支付订单、不调起付款、不发起真实退款。
- 不领取优惠券、不兑换礼品卡、不绑定或解绑剪刀、不提交售后。
- 不上传小程序、不修改微信公众平台或支付配置。
