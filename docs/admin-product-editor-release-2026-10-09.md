## 设计及实现

目的：减少运营人员填写商品资料时的混排和定位成本。采用专业工具台式分区布局，左侧表单、右侧预览；沿用后台品牌字体 Geist 与中文字体回退、棕色 #9B6234、白色 #FFFFFF、浅灰 #F5F6F8、文字 #1D1D1F、辅助灰 #86868B。未引入新字体、组件库或主题。

1. 基础资料：系列→剪型→目录关联，名称、短名称及简介。
2. 商品图片：封面/轮播/详情区分，显示 1/7/30 上限与当前数量；保留排序及上传事件。
3. 参数与质保：保留原参数、质保字段与 0 值含义，不改承诺。
4. 型号规格：各型号独立卡片，图片与卡片图单独上传，名称/价格/SKU 明确标注；发货方式及天数保持可见，补充资料可展开，非普通发货自动展开。使用原生 details 保留输入状态，不删除表单节点。
5. 销售设置：集中商品价格、库存、上架、推荐和优惠券设置。

顶部五个分区链接仅滚动定位，不修改 hash 路由。底部固定保存/取消栏保留原确认与保存逻辑。商品预览保留并限制高度；较窄桌面宽度改为单栏。作用页面为 ProductCreate.vue（共享新建、编辑、删除路由），未改写数据模型、接口或权限。

界面设计技能要求先明确设计规范；网页开发技能要求先确认范围、构建及浏览器验证。现有字体/品牌视觉与 Element Plus 是项目约束，因此复用既有系统，未换成技能默认的其他风格。浏览器环境没有 agent-browser，使用既有 Playwright/Chrome 进行等价真实浏览器检查，未安装新业务依赖。
