# 商品上传一次、两端共用接口：本地核验

日期：2026-10-09。工作区：E:\sravxapp。状态：仅本地修改，未部署、未发布小程序、未 Git 提交/推送。

## 范围与合同

普通商品由现有管理端创建/更新接口维护，保存至目标商品仓库；网页与小程序公共目录读取统一使用 `/api/v1/catalog/`，共用 `common/api.js`、`product-classification.mjs` 和 `web-purchase.mjs`，不复制商品记录。

| 信息 | 共用来源与处理 |
| --- | --- |
| Basic / Pro / Master / 配件及剪型 | 保存的 params 目录元数据优先；兼容分类父子关系；配件不套用剪刀分类 |
| 名称、说明、技术参数、质保 | 同一商品详情及参数适配，不按商品名称猜测新资料 |
| 封面、相册、详情、型号图、卡片图、SKU 图 | 数据库保留对象引用；公共读取响应解析为 HTTPS 临时地址 |
| 普通型号、颜色、价格、库存 | 两端共用选择逻辑；缺失价格不伪装成零元，显式零值保留；零/非法库存不可购买 |
| 结构化型号 × 颜色 SKU | 共用选配解释；购买放行仍服从原开关，不降级成普通商品 |
| 发货承诺、延迟原因、备注 | 随所选型号/SKU 更新；明确空值不继承另一型号的说明 |

公共接口失败明确报错，不再自动退回 CloudBase 商品函数，避免展示两份不同商品数据。旧交易函数不因此退役。

## 媒体与安全边界

- `server/src/media/public-catalog.js` 在目录仓库完成已发布/可见过滤后解析媒体，不提供匿名任意对象签名接口。
- 仅解析发布记录引用的 `catalog/products/`、`catalog/categories/`、`catalog/banners/`、`catalog/points-products/` 对象；签名由已有 COS signer 生成，有效期 900 秒，响应带 `media_expires_at`。
- 同一响应内重复对象只签名一次；不会把临时地址覆盖写入数据库。已存在 HTTPS 或 `/static/` 地址保留；不支持的私有引用不暴露，不猜测域名。
- 网页详情返回可见页面或图片出错时检查过期并重新读取；小程序详情重新显示时检查过期。目录长时间停留、分享卡片的远期图片有效性仍需后续真机/浏览器验收。
- 历史 `cloud://` 文件没有经批准的映射，不能保证自动兼容；需另行盘点与受控迁移。没有导出或复制这些文件。
- 未改变上传权限、管理员认证、数据库结构、订单/支付放行开关；没有回显环境变量、请求头或私有运行凭证。按 CloudBase code-review 规则做语义核验；本次商品媒体使用 COS 签名，不增改 CloudBase 安全域名。
