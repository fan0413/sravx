## 商品读取故障修复与真实接口复验

后续入口简化：`pages/purchase/index` 仅作为商品解析兼容入口，不再显示商品卡片。按目录原顺序进入当前系列/剪型的首个匹配商品，通过替换路由避免浏览器返回时重新进入解析页再跳转。真实目录“购买”点击直接进入选配；刷新保留详情；页面返回与浏览器返回均回产品目录；无匹配商品不跨系列跳转。更新自动回归脚本断言购买入口直接显示选配且没有中间卡片，回归与 9 项单元测试、H5 构建通过。本次没有生产发布或交易写入。

- 故障基线：在 `localhost:5173` 打开 Basic 直剪购买入口，公开接口响应缺少本地 Origin 的跨域允许头，浏览器拦截后误调用 `wx.cloud`，页面显示“云能力未初始化”。此前模拟数据测试未覆盖这一实际连接问题。
- 本地修复：`vite.config.ts` 添加固定上游的 `/sravx-catalog` 同源代理，仅允许公开目录 GET，拒绝其他路径/方法，剥离 Authorization/Cookie。H5 开发目录读取走该代理，生产构建仍用正式 API 或显式 `VITE_SRAVX_CATALOG_BASE_URL`；生产部署必须验证同源反向代理或明确的 CORS 白名单，不依赖 Vite 开发服务器。
- H5 目录错误保留 HTTP/网络错误，不再错误调用小程序云接口。小程序保留原目录回退，认证、订单、库存及支付放行不变。
- 真实接口验证（无网络拦截、无业务写入）：分类 GET、Basic 直剪列表 GET、详情 GET 均为 200；购买入口出现标注“请勿下单”的测试商品；进入详情出现选配汇总，刷新 URL 不变，详情再次 GET 200；未捕获页面异常。
- 回归：目录传输 3 项与选配 6 项单元测试全部通过；隔离浏览器规格/数量/购物袋/刷新/手机布局/导航/边界检查通过；H5 构建及小程序 26 页构建通过。没有创建真实订单、发布网站或修改生产配置。
