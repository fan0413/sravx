## 边界

- 本次是渠道工作区与功能入口分组，不是独立渠道 CMS。欢迎页、官网首页、顶部导航仍由源码维护；轮播记录没有渠道字段，不因切换自动隔离。
- 独立页面编辑、渠道商品展示/排序配置尚待后续数据契约与前端接入；本次没有虚构可保存的配置界面。
- 未使用真实管理员凭证验证生产 API；未提交订单、发布商品、变更价格/库存/支付、部署或 Git 推送。
