# 统一账户身份架构

## 目标

`users.id` 是全站业务主体。小程序、网页和后续应用通过身份绑定登录同一用户，不以应用范围内的 OpenID 作为业务外键。

## 身份绑定

`user_identities` 的唯一键为 `(provider, provider_subject)`：

- `wechat_unionid`：同一微信开放平台下的跨端身份。
- `wechat_miniprogram_openid`：小程序应用内身份，用于 UnionID 尚不可得时的兼容登录。
- `phone_e164`：后续网页验证码登录的标准化手机号身份。

绑定必须由服务端验证登录凭据后写入。禁止用昵称、头像、客户端传入的用户 ID 或未验证手机号自动合并账号。

## 会话

`user_sessions` 继续按设备/浏览器保存会话摘要。网页使用 Secure、HttpOnly Cookie；小程序使用受保护的 Bearer 令牌。两者都必须查询持久化会话状态以支持撤销。

## 放行前条件

1. 微信小程序与网站应用绑定到同一微信开放平台账号，并验证可取得一致 UnionID。
2. 网页短信服务、频率限制、验证码审计与账号绑定确认流程完成。
3. 对历史只含 OpenID 的用户执行受控绑定，不做自动合并。
