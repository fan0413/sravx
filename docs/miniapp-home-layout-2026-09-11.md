# 小程序首页视觉优化记录（2026-09-11）

## 参考与目标

参考负责人提供的视频中的产品发现结构：顶部产品标题、横向分类卡、胶囊筛选、单张主推卡和分组商品卡。实现沿用 Sravx 的品牌、商品、分类与轮播数据，不使用参考品牌名称、商标、文案或图片。

## 本次改动

- 首页按“产品 → 分类入口 → 需求筛选 → 主推轮播 → 商品精选”重新分层。
- 分类卡由实时分类和已有商品主图生成；无图片时回退为本地品牌标识。
- 主推轮播和商品卡继续使用现有数据源；点击可进入商城或商品详情。
- 保留现有自定义导航、下拉刷新、缓存预取、轮播切换和底部 Tab 行为。

## 验证

- `node --check miniprogram/pages/home/home.js` 通过。
- `node --check miniprogram/utils/preload.js` 通过。
- `git diff --check` 通过。
- 当前工作机未检测到微信开发者工具，未进行模拟器或真机视觉验收；发布前需在 iPhone 与 Android 模拟器检查安全区、横滑分类、长名称截断、空数据、轮播图片和商品跳转。

## 第二轮视觉微调

- 分类卡片由 144rpx × 154rpx 增至 174rpx × 190rpx，图片与文字同步放大。
- 主推轮播的文字信息层收窄到卡片底部，避免遮盖主图。
- 自定义底部 Tab 改为半透明白色表面、细分隔线与轻阴影；标签字体提高至 22rpx，当前项使用更深颜色和更明显的图标描边。

## 第三轮：高端工具视觉语言

- 主推卡按苹果三段结构设为 694rpx × 860rpx：474rpx 产品视觉、222rpx 文案、164rpx 行动区。
- 取消图片文字叠层；轮播标题、系列说明和行动按钮均在独立白色信息区展示。
- 全局文字色统一为石墨黑 `#161616`、中性深灰 `#636366`；强调色统一为暖金属棕 `#8A6A42`，用于价格、栏目眉题和次级行动。

## 我的剪刀资产卡

- “我的”页预览与“我的剪刀”列表统一为三段卡：产品图、名称规格、SN 与保修信息。
- 取消覆盖产品图的大面积渐变，图片保留独立展示空间。
- 使用 `SRAVX REGISTERED TOOL` 小型登记标识、石墨黑信息文字和暖金属棕保修强调色，突出可追溯的专业工具资产。
