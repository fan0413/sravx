# 默认客户端服务器单来源适配

日期：2026-10-09。主工作区：E盘。依据：负责人明确说明旧环境已过期并要求全部使用服务器。

## 本次范围与结果

- UniApp/H5共用API取消迁移开关与云函数回退，App不初始化旧环境。默认HBuilderX源码与CLI构建一致。
- 服务器订单唯一列表；显式cloud来源缓存订单不允许解释为同编号服务器订单。普通/积分支付参数只取服务器；资金及库存仍由服务器裁决。普通退款申请走服务器，客户端不直接执行退款。
- 管理端登录、目录、运营模式默认服务器，缺省API域名为现用API。删除CloudBase浏览器SDK依赖，历史未迁移适配器不发网络请求并明确拒绝操作。
- 商品图片继续使用现有私有COS/服务器签名机制，不购买CDN，不把数据库和图片搬到API机器。

## 核验

- 前端 `node --test scripts/*.test.mjs`：76/76通过，含38项API路由矩阵、默认无迁移开关、旧来源拒绝、合成登录、地址选中与单标题栏。
- 管理端隔离测试：8/8通过，含默认模式、合成登录/会话/退出路由与旧适配器无SDK/无请求检查。
- 微信默认构建：26页，无分包；产物核验登录/地址/订单/支付服务器路由及无旧云初始化通过。
- H5构建通过；管理端vue-tsc与Vite构建通过，原大分块警告仍存在。卸载旧SDK后依赖审计报告6项high，未擅自批量升级依赖。
- 只读现网检查：API与nginx服务active，服务器本机readyz200；公开目录/分类/积分商品/可领优惠券GET200，受保护用户/地址/订单/积分订单/工具/退款/礼品卡记录无会话GET401。401只证明鉴权存在，不证明业务完整验收。
- 本机未找到agent-browser及可直接使用的Playwright包；未用真实账号进行浏览器自动操作。HBuilderX实际编译与微信真机保存地址/下单/支付仍由负责人复验。

## 明确缺口（不得当作已完成）

1. 管理端优惠券、礼品卡维护没有服务器路由，目标菜单继续隐藏，旧函数仅拒绝。部分旧顺丰自动操作、物流同步、地址修改及延期记录操作也尚未迁移。
2. 管理端用户积分/等级/状态变更、剪刀售后状态更新未迁移；现有读取/消息/服务地址接口可路由服务器。
3. 积分订单退款申请没有独立服务器持久化与退款账本，不得套用普通订单退款；目前明确拒绝并提示人工处理。H5账户登录仍为原占位流程。
4. 客户端结构化结算指向服务器，但线上STRUCTURED_CHECKOUT_ENABLED未启用，不擅自开启交易开关。
5. 所有旧函数与表/对象核验、停写最终快照等迁移门槛仍按执行计划进行；环境过期不等于允许删除旧资源，也不等于历史数据无需核验。
