# 项目介绍

## 为什么做这个项目

宠物美容工具需要展示规格、剪型和图片，还需要一个后台维护商品。我把官网、小程序和管理端放在一个项目里，让它们使用同一套后端数据。

开发中使用了AI辅助。面试时按自己实际做过、看懂的部分讲解，不把整个项目说成完全独立手写，也不编造工作经历。

## 可以演示什么

1. 打开https://sravxpet.com，拖动鼠标切换剪刀，说明当前商品名称和暂停功能。
2. 点击进入官网，通过产品导航看系列、商品价格和详情，再刷新页面。
3. 打开api.js和接口说明，讲解页面怎样向后端拿数据。
4. 看商品分类或价格测试，说明改动后如何检查原功能。

后台可以在本地用模拟数据演示，不向别人提供生产账号，不演示真实付款或退款。

## 开发中遇到的问题

| 问题 | 处理方法 |
|---|---|
| 两个客户端分类不一致 | 共用分类和价格处理函数 |
| 页面刷新后才更新 | 检查路由参数和页面刷新逻辑 |
| 图片临时地址过期 | 重新查询商品，不把签名地址存回数据库 |
| 已过期云环境仍被调用 | 把用户端请求集中改到服务器接口 |
| 拖动后误点到图片 | 区分点击和拖动，松开后再切换 |
| 页面构建成功但上线不一定正确 | 检查服务器文件、HTTPS和实际浏览器页面 |

## 还需要完善

网页登录和完整网页支付需要继续验收；小程序也需要更多真机检查。管理端有较大的打包文件，后面可以再拆分。测试命令目前主要手动执行，还没有完整自动发布流程。
