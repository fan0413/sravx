# 微信登录迁移接入要求

更新：2026-09-10。本文件用于准备 `login` 云函数向云服务器 API 的替换，不含 AppID、AppSecret、用户资料、会话令牌或任何可用凭据。

## 目标行为

小程序通过 `wx.login()` 获取一次性 code，云服务器在服务端向微信交换身份标识，并创建受控会话。后续用户、地址、订单、礼品卡和剪刀接口只依据该会话确定用户，不读取请求体中的 OpenID 或用户 ID。

## 上线前需由负责人或运维在受控位置配置

| 配置项 | 存放位置 | 用途 | 不可接受的做法 |
|---|---|---|---|
| 小程序 AppID | 服务器受控环境配置 | 微信身份交换的应用标识 | 写入小程序请求参数、公开接口响应或日志。 |
| 小程序 AppSecret | 服务器仅可读机密配置 | 服务端调用微信身份交换接口 | 提交 Git、写入普通 Markdown、放进前端包或聊天。 |
| 会话签名密钥 | 服务器仅可读机密配置 | 签发与校验服务端会话 | 使用固定示例值、复用支付密钥或记录在数据库业务表。 |
| 会话失效与撤销存储 | 目标 MySQL 的独立会话/撤销表，或等价受控存储 | 登出、换机、强制失效与密钥轮换 | 只依赖不可撤销的长期 Token。 |
| 手机号授权策略 | 微信官方手机号能力与服务端验证设计 | 绑定已授权手机号 | 接收客户端声称的手机号或明文解密结果。 |

## 接口边界

1. `POST /api/v1/auth/wechat/session` 只接收短期 code；服务端校验长度、频率和重放风险后调用微信。
2. 微信响应和会话签发仅在服务端处理；日志记录请求 ID 和结果分类，不记录 code、OpenID、手机号、session_key 或 Token。
3. 会话 Token 置于标准 `Authorization: Bearer` Header；用户身份、角色和权限不从请求体获取。
4. 管理端会话独立于小程序客户会话，默认无管理员权限；管理员角色只能经受控后台流程授予。
5. 支付下单、支付回调、退款和物流不使用本模块作为支付鉴权替代，仍按支付专项最后实施。
